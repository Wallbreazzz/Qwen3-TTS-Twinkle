# TTS 数据集录制指南（客户版·简要）

> 本文件是给**客户与录音团队**的简要录制指南，一表速查。
> 每条含"专业词汇是什么 + 为什么要这么做"。详细版与全部依据见 `docs/03-数据集录制标准与方案.md`。
> 目标模型：Qwen3-TTS / MOSS-TTS-Local-v1.5（CosyVoice2 作对照）。

---

## 一、录音棚与环境

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 在吸音房间录，**RT60 < 0.4 秒**；禁止空旷硬质房间（玻璃/瓷砖/大厅） | **RT60（混响时间）**：声音衰减 60dB 所需时间，越短越"干" | 混响会被模型学进音色，合成语音带"厅堂感"、拖泥带水；干声才能让模型只学说话人特征 |
| 背景噪声 **NC-15~NC-20**，关空调/风扇/冰箱/窗，空录底噪 **< -60 dBFS** | **NC（噪声曲线）**：按频谱评室内背景噪声等级；**dBFS**：满量程分贝，0=最大 | 底噪会被模型学进 token 分布，合成始终带"嘶嘶"声；不同段噪声不同→音色漂移 |
| 用**大振膜电容麦 + 心型指向 + 幻象电源**（如 AT2035/Rode NT1） | **电容麦**灵敏高频响宽；**心型指向**正面拾音背面抑制；**幻象电源 +48V** 给电容麦供电 | 灵敏度高还原细节；心型指向避开背后噪声；动圈麦/手机麦信噪比差 |
| 拾音距离 **10-15 cm**，**45° 侧对**麦头，装**防喷网** | **近讲效应**：太近低频提升发闷；**防喷网**：挡爆破音气流 | 太近发闷太远信噪比降；45°侧对 + 防喷网避免"p/b/t"气流直击振膜产生爆破 |
| 同一房间、同一麦克风、同一增益、同一时段录完全部 | **统一性铁律** | 中途换设备/房间→模型学到"设备/房间特征"而非说话人特征，音色漂移，作废重录 |

## 二、录音人员

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 用**面客实际语速/语调/音量**朗读 | **面客**：实际对客服务时的状态 | 目标是用模型替代面客语音，须匹配真实服务场景，否则合成与真人脱节 |
| 会话内保持**音色一致**，避免前后音量差异明显 | **音色漂移**：录音过程中声音特征变化 | 音色不一致→模型无法收敛到稳定音色 |
| 每连续录 **15~20 分钟休息**一次（5~10 分钟） | **声带疲劳**：长时间用嗓后声带紧张 | 疲劳后音色发紧发闷音量下降，模型学到"前半段新鲜+后半段疲劳"不一致分布 |
| 每条语料**读 2 遍**存 2 个文件（可选，见下注） | **鲁棒性**：模型适应变化的能力 | 1 遍即可训练；2 遍买鲁棒性但**双倍工期**。预算紧录 1 遍、追极致音色录 2 遍，先与客户对齐 |
| 情绪以**平静为主**，可含少量不同句型/语气 | **韵律**：语速、停顿、语调起伏 | 数据单一则模型学不到多样表达；但精确语气控制超出本项目，自然朗读即可 |

## 三、音频规格

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 母带录 **48 kHz / 24-bit / 立体声 / WAV(PCM)** | **采样率**：每秒采多少点；**位深**：每点用多少比特；**PCM**：无损原样存波形 | 48k 能干净 2:1 降到目标模型 24k（三模型通用）；24-bit 留剪辑降噪余量；立体声匹配 MOSS 原生格式 |
| 派生训练子集：**Qwen3-TTS → 24kHz/单声道/16-bit；MOSS → 48kHz/立体声** | **单声道（mono）**：一个声道；**重采样**：改采样率 | 各模型 codec 有硬要求：Qwen3 代码强制 24kHz 单声道（否则报错）；MOSS 原生 48kHz 立体声 |
| 用 **WAV + PCM 无损**，**不要用 MP3** | **有损压缩**：MP3 丢弃高频引入伪影 | MP3 削掉高频、引入压缩伪影，被模型学进去就是"噪声底子"，不可逆 |
| 单条 **5~15 秒**，过长在标点处切断 | **注意力窗口/显存**：模型一次处理的长度上限 | 太长爆显存、文本音频对齐漂移、长句情绪难一致；短句训练更稳 |

## 四、音频质量

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 峰值 **-6~-12 dBFS**，最大不超 -3 dBFS，**绝不到 0 dBFS** | **削波（clipping）**：信号超满量程被截断，0 dBFS=削波 | 削波是不可逆失真，对应 audio token 被"污染"，模型可能学到爆破杂音 |
| 无**直流偏移**，**< ±0.5%FS**，暂停时波形居中 | **DC 偏移**：波形中线偏离 0 整体上移/下移 | DC 偏移让能量计算错、削波不对称（先削一边）、codec 编码偏移 |
| 信噪比 **SNR ≥ 35 dB**（理想 ≥40） | **SNR（信噪比）**：语音信号与背景噪声的强度差 | SNR 低则语音信息占比少，模型学进去噪声多；专业棚录可达 40-60dB |
| 归一化到 **-23 LUFS**，True Peak **≤ -1 dBTP** | **LUFS**：响度单位（K 加权）；**True Peak**：过采样重建的真实峰值 | 全数据集响度统一，避免各条音量忽大忽小；真峰不超 -1 防削波 |
| 录制首尾留 **500ms~1s 静音**，成品裁到 **300ms** | **padding（静音边距）** | 录制留余量给后期裁剪/对齐；成品 300ms 是多数 TTS pipeline 的边界对齐惯例 |
| 自动 QC：**DNSMOS ≥ 3**（<3 重录/丢） | **DNSMOS**：微软自动语音质量打分（1-5，基于 SIG/BAK/OVRL） | 自动筛掉明显坏的条目，比纯靠耳朵客观可量化 |

## 五、文本与转写

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 转录**100% 准确**，按**实际发音**逐字写，不按脚本 | **转录（transcription）**：把语音转成文字；**逐字对齐**：文字与发音一一对应 | 文本与发音不符（加字/漏字/口误）→教模型读错字，loss 会降但合成乱码；改转写不改音频 |
| **文本归一化**：金额/卡号/日期/英文缩写规定读法并写进转写 | **TN（Text Normalization）**：书面符号→实际读音文字 | 模型不认数字符号，要学"怎么读"；银行话术大量含金额卡号，不归一化则读法混乱 |
| 语料覆盖**声韵母组合全**、不同句型/语速 | **音素平衡**：语料覆盖所有发音单元 | 文本多样性 > 纯时长；只录平淡朗读则克隆拟人化上限低，学不到多样表达 |
| 总时长 **15~30 分钟**（smoke test 可 5 分钟） | **微调（fine-tuning）**：用少量数据再训基础模型 | 少样本微调下限<1 分钟，但 15-30 分钟更稳妥（超工业克隆 30 分钟下限） |

## 六、文件管理与元数据

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 命名 `音色ID_语料号_第n遍_会话ID.wav`（如 `spk001_0007_v2_s03.wav`） | **命名约定** | 批量训练要程序化配对音频与文本，命名乱则无法配对 |
| 每条音频配**同名 JSON 元数据**（说话人/性别/年龄/采样率/文本/情绪/是否含数字英文/录制日期/设备） | **元数据**：描述数据的数据 | 便于程序化读取、溯源、按维度筛选（如只训平静情绪） |
| 拆 **10-20% 不重叠句**作验证集，且验证集**文本必须是训练集没见过的** | **过拟合/验证集（val）**：验证集测泛化 | 验证集与训练集重复→看不出过拟合，只能盲猜训练轮数（这是反面教材的根因） |

## 七、法规与授权（前置门槛，不签不录）

| 注意事项 | 专业词汇·是什么 | 为什么要这么做 |
|---|---|---|
| 录制前签**授权使用书**，可商用 | **声纹**：人声的生物特征，属**敏感个人信息** | 《个人信息保护法》《民法典》：声纹唯一识别自然人，无授权=非法数据，商用法律风险 |
| 授权书含：**范围**（三模型商用衍生品）、**期限**（起止可撤回）、**用途限制**、**可撤回条款** | **商用衍生品**：用该音色训练出的模型及其服务 | 范围不明则后续商用越权；期限与可撤回保障录音人权益，需约定已训练模型的撤回处理方式 |

## 一句话速记

**吸音房间、电容麦 10-15cm、48kHz/24-bit/立体声、峰值 -6dBFS 不削波、每 15 分钟休息、录 15-30 分钟、转写按实际发音+银行 TN 归一化、DNSMOS≥3、命名+元数据齐全、签授权书。**
